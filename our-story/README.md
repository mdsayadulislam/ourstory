# Our Story ❤️ — Md Sayadul Islam & Mim Akter

A luxury, mobile-first romantic anniversary cinematic movie and interactive storybook journey crafted especially for **Md Sayadul Islam** and **Mim Akter**. Built with **pure static web technologies** (HTML5, CSS3, and Vanilla JavaScript), with **no build step, no npm, and no backend needed**.

---

## 🌹 Special Features & Highlights

- **Strict Access for Mim Only**: The universe is locked exclusively for username `Mim`. Nobody else can enter!
- **Storybook Flow Experience**: Rather than a disconnected dashboard app, this is a smooth, continuous romantic narrative that flows from chapter to chapter with "Continue The Story ⬇️" bridges.
- **The Romantic Love Express & Cycle Journey**: Animated vintage tandem bicycle & romantic steam train gliding through a starry moonlit sky, puffing heart smoke (`❤️ ☁️`) with interactive whistle chime bells!
- **Interactive Love Test Quiz**: "How Well Do You Know Our Love?" with funny & romantic questions, instant heart confetti reactions, and an Eternal Soulmate Trophy!
- **Midnight Heart Catcher Mini-Game**: Glowing hearts fall from the moonlit night sky. Catch 10 hearts to unlock Sayadul's secret love chest with an intimate love letter!
- **Sequential Story Chapters & Real Photos**: Features real photos (`pic1.jpeg` through `pic5.jpeg`) woven throughout the narrative chapters.
- **Realistic 3D Love Letter Envelope**: Wax-sealed interactive envelope that physically unseals and slides out Sayadul's handwritten letter for Mim.
- **Three.js Cosmic Starfield**: Celestial 3D cosmos where "Sayadul" and "Mim" soul stars converge and merge into a cosmic glowing heart on scroll.
- **Dual-Mode Audio Engine**: HTML5 Audio player with visual equalizer bars and a procedural Web Audio API romantic piano/celesta lullaby synthesizer fallback.

## 🚀 How to Run & Deploy

### Run Locally
Simply double-click [`index.html`](file:///d:/Aniversary/our-story/index.html) in any web browser (Chrome, Edge, Safari, Firefox). No installation needed.

### Deploy Online
- **GitHub Pages**: Push this directory to GitHub, go to **Settings** > **Pages**, and choose the `main` branch.
- **Netlify**: Drag and drop the `our-story` folder directly onto [Netlify](https://www.netlify.com/).
- **Vercel**: Import repository as a static project.
